# 🚀 Sandeep — Premium Data Analyst Portfolio

A modern, highly animated, responsive, production-ready **Data Analyst & Business Intelligence Portfolio Website** designed for **Sandeep** (Final Year B.Tech IT Student at J.C. Bose University of Science and Technology, YMCA).

Built with **React**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, **Lucide Icons**, and **Recharts**, featuring an end-to-end **centralized data architecture** for effortless future updates.

---

## ✨ Key Features

- 👨💻 **Professional Positioning**: Positioned as an Aspiring Data Analyst specializing in Python, SQL, Excel, Power BI, Tableau, EDA, and Data Visualization.
- 🎨 **Futuristic Dark Data Theme**: Electric blue, cyan, and purple accents with glassmorphism, dynamic node-grid canvas, custom smooth cursor, and dark aesthetics.
- ⚡ **Advanced Motion System**: Smooth Framer Motion transitions, cycling phrase typing animations, card hover tilts, and interactive step workflows.
- 📈 **Featured Projects & Interactive Case Studies**:
  - **Sales Performance & Profitability Analysis** (Intermediate BI & SQL Project with interactive charts, KPIs, SQL queries, & strategic recommendations).
  - **Netflix Content & Trend Analysis** (Intermediate EDA Project with Movie vs TV show ratios, genre breakdown, & yearly addition trends).
- 🎓 **Verified Education Timeline**: Includes official addresses, campus images, map search integration buttons, and website navigation links for:
  - J.C. Bose University of Science and Technology, YMCA (B.Tech IT - 7th Semester)
  - White Leaf Public School, Bawana, Delhi (Class 12th)
  - Holy Child Senior Secondary School, Hisar, Haryana (Class 10th)
- 🧩 **Centralized Editable Data Architecture (`src/data/`)**: Update resume info, bio, skills, education addresses, projects, and social links without altering UI JSX components.
- 📱 **Fully Responsive & Accessible**: Tested across desktop, tablet, and mobile displays with `prefers-reduced-motion` support.
- 🔍 **SEO & Security Ready**: Built with OpenGraph meta tags, `robots.txt`, `sitemap.xml`, `.env.example`, and secret-free codebase.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, Vite, HTML5, CSS3, JavaScript (ESNext)
- **Styling**: Tailwind CSS v4, Custom Glassmorphism, CSS Animations
- **Animations**: Framer Motion, Canvas Particle Node Grid
- **Charts & Visualizations**: Recharts
- **Icons**: Lucide React
- **Celebrations**: Canvas-Confetti

## ⚡ Quick Start & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sandeepydv14/sandeep-data-analyst-portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
